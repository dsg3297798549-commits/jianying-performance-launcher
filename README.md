# 剪映性能启动器

一个面向 Windows 的第三方剪映专业版启动工具。启动前为剪映绑定高性能 GPU，运行中持续解除其进程的 EcoQoS 节流，并避免渲染子进程被降到过低优先级。

> 本项目是第三方非官方工具，与剪映、抖音或字节跳动不存在隶属、合作或认可关系。软件不会修改剪映程序或工程文件。

## 功能

- 自动识别正在运行的剪映或默认安装目录中的最新版本。
- 从 Windows 卸载注册表和常见磁盘目录查找自定义安装位置。
- 找不到时允许手动选择 `JianyingPro.exe`，并记住该路径。
- 写入 Windows 用户级高性能 GPU 偏好。
- 将剪映主进程及其渲染、解码子进程调整为“高于正常”优先级。
- 关闭剪映进程的 EcoQoS/执行速度节流。
- 每 3 秒接管新创建的剪映子进程。
- 不关闭、不暂停，也不降低其他应用的优先级。

## 使用

1. 在 [Releases](../../releases) 下载最新的 `剪映性能启动器.exe`。
2. 保存并退出当前剪映。
3. 双击启动器，在窗口中点击“优化并启动剪映”。
4. 保持启动器窗口打开，以持续监控剪映子进程。

首次运行时，Windows SmartScreen 可能提示未知发布者。这是因为免费发布版本未使用商业代码签名证书。你可以下载源代码自行审查和编译。

## 系统要求

- Windows 10 或 Windows 11
- 已安装剪映专业版
- .NET Framework 4.x（Windows 10/11 通常已自带）
- 不需要管理员权限

## 工作原理与限制

启动器通过 Windows 官方进程和注册表接口设置 GPU 偏好、进程优先级及电源节流状态。GPU 利用率不会始终达到 100%；素材编码格式、特效、内存容量、磁盘速度和剪映自身调度都可能成为瓶颈。

本工具不清理缓存、不修改工程文件，也不会解锁或绕过剪映的任何功能。

## 从源码构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

生成文件位于 `dist\剪映性能启动器.exe`。

## 日志

运行日志保存在：

```text
%LOCALAPPDATA%\JianyingOptimizer\launcher.log
```
